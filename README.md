# RFM-анализ клиентской базы и товарный анализ аптечной сети для оптимизации механизма СМС-рассылок

## 🎯 Описание проекта

Проект направлен на сегментацию клиентской базы аптечной сети путем RFM-анализа (Recency, Frequency, Monetary) с целью подготовки рекомендаций по маркетинговым действиям (персонализированные смс-рассылки). 

## 📋 Цели и задачи

### Цель
Выделить группы клиентов, понять их поведение и дать практические рекомендации, чтобы эффективно расходовать маркетинговый бюджет.

### Задачи
- Подготовить данные и проверить их качество.
- Рассчитать RFM‑метрики на уровне покупателя (карты).
- Сегментировать клиентов и описать профиль каждого сегмента.
- Сравнить поведение идентифицированных клиентов и анонимных транзакций (для понимания смещения выборки).
- Проверить возможность привязки товарных позиций (sales) к картам для персональных товарных рекомендаций.
- Подготовить финальный отчет с конкретными предложениями по кампаниям.
- Подготовить дашборд в Metabase для отслеживания состояния и поведения клиентской базы.
